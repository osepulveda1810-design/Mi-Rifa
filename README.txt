MI RIFA — VERSION INSTALABLE

Esta carpeta contiene la aplicación y los archivos necesarios para instalarla como PWA.
Debe publicarse completa en una dirección HTTPS (por ejemplo, GitHub Pages) para que el navegador permita instalarla. No basta con abrir index.html como archivo local.

Después de publicarla, abre el enlace HTTPS en Chrome/Edge y elige Instalar aplicación o Añadir a pantalla principal. La app abre en modo de pantalla completa/ventana independiente.

Los datos de la rifa quedan en el almacenamiento local del navegador de cada dispositivo; no se sincronizan entre equipos. Usa Respaldo/Importar para trasladar la información. Antes de usar esta versión, importa tu respaldo JSON.
